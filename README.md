# StatPilot AI 📊

**AI-Powered Statistical Analysis & Machine Learning Assistant**

StatPilot AI is a Streamlit web app that lets users upload a dataset and instantly explore it, clean it, query it in plain English, ask questions over its documentation, and train baseline machine learning models — all without writing a single line of code.

🔗 **Live App**: [https://statpilotai.streamlit.app]

---

## Features

### 1. Dataset Overview
Upload a CSV or Excel file and instantly see rows, columns, duplicate counts, data types, and missing value percentages in a clean summary table.

### 2. Data Cleaning
- Custom NaN marker detection and handling
- Data type conversion
- Missing value handling
- Duplicate row removal
- IQR-based outlier detection, with options to remove or cap outliers
- AI-assisted cleaning: describe a cleaning operation in plain English, and Groq LLM generates a SQLite `UPDATE` statement — shown for preview and approval before it's applied, with a keyword blocklist as a safety check

### 3. Exploratory Data Analysis (EDA)
- **Numeric columns**: Histogram, Box Plot, Violin Plot, or Scatter Plot (user-selectable) + correlation heatmap
- **Categorical columns**: Bar Chart, Pie Chart, or Frequency Table
- All visualizations powered by Plotly for interactivity

### 4. Ask Your Documentation (RAG)
Upload a PDF (data dictionary, methodology notes, etc.) and ask questions about it in plain English. The document is parsed page-by-page, split into overlapping chunks, embedded using a Sentence-Transformer model, and indexed with FAISS for similarity search. Answers are generated by the Groq LLM, grounded strictly in the retrieved chunks, and returned alongside the source page number(s) they came from.

### 5. AI Chat With Dataset
Ask questions about your data in plain English. StatPilot AI uses the Groq LLM (Llama 3.3 70B) to convert your question into a SQL query, runs it against an in-memory SQLite representation of your dataset, and shows you both the result and the generated SQL — so you can learn and verify as you go.

### 6. Machine Learning
- Select a target column and features
- Auto-detects classification vs. regression (with manual override)
- Per-column missing-value handling (Auto/Median/Mode/Zero/Custom)
- Smart detection of numeric columns that are actually categorical
- Automatic encoding: One-Hot for low-cardinality, Target Encoding (with smoothing) for high-cardinality categorical features
- Trains and compares 2 baseline models per task (Logistic/Linear Regression + Random Forest)
- Optional sampling for datasets over 50,000 rows, to keep training fast

## Tech Stack

| Layer | Tools |
|---|---|
| Frontend/App | Streamlit |
| Data Handling | Pandas, NumPy |
| Visualization | Plotly |
| Machine Learning | scikit-learn |
| Embeddings | Sentence-Transformers (`all-MiniLM-L6-v2`) |
| Vector Search | FAISS |
| LLM | Groq API (Llama 3.3 70B Versatile) — powers NL-to-SQL, RAG Q&A, and AI-assisted data cleaning |
| Query Engine | SQLite (in-memory) |

## Running Locally

1. **Clone the repo**
```bash
   git clone https://github.com/adarshtiwarirewa-byte/StatPilot-AI.git
   cd StatPilot-AI
```

2. **Install dependencies**
```bash
   pip install -r requirements.txt
```

3. **Add your Groq API key**

   Create a `.env` file in the root directory:
   ```
   GROQ_API_KEY=your-api-key-here
   ```

4. **Run the app**
```bash
   streamlit run app.py
```

## Deployment

This app is deployed on [Streamlit Community Cloud](https://streamlit.io/cloud). The Groq API key is managed via Streamlit's Secrets manager rather than a `.env` file in production.

> **Note:** The RAG feature depends on `torch` and `sentence-transformers`, which are resource-heavy for Streamlit Community Cloud's free tier — confirm whether RAG is currently live-deployed or running locally-only before this section goes public.
